ENVIRONMENT SETUP FOR GAMERCONNECT PROJECT

1. Project structure
- GamerConnectAPI/: Node.js/Express backend and MySQL integration
- gamerconnectmobile/: Flutter mobile application
- docker-compose.yml: Docker services for backend API, MySQL, and Flutter app
- gamerconnect.sql: MySQL database schema and seed data

2. Required software
- Windows 10/11 or compatible OS
- Docker Desktop with Docker Compose
- Node.js 18+ and npm
- Flutter SDK with Dart
- Optional: Android Studio / Xcode for mobile emulator/device

3. Backend environment
- Backend source: GamerConnectAPI/
- Database connection file: GamerConnectAPI/db.js
- Environment config: GamerConnectAPI/.env
- Default `.env` values used by backend:
    DB_HOST=gamerconnect-mysql
    DB_USER=gameruser
    DB_PASSWORD=gamerpass
    DB_NAME=GamerConnect
    PORT=3000

4. Starting with Docker Compose
From the project root `GamerConnectAPI-Mobile`:
    docker compose up -d

This starts:
- `db`: MySQL 8.0 container
- `api`: Node.js backend container
- `flutter`: Flutter container for the mobile/web frontend

5. Backend local setup without Docker
If Docker is not used:
- Install MySQL and create a database named `GamerConnect`
- Execute the SQL script: `mysql -u root -p GamerConnect < GamerConnectAPI/gamerconnect.sql`
- Install backend dependencies:
    cd GamerConnectAPI
    npm install
- Update `GamerConnectAPI/.env` to use local database host:
    DB_HOST=localhost
- Start backend:
    npm start

6. Flutter frontend setup
From `gamerconnectmobile`:
    flutter pub get

Run the Flutter app on your target device/emulator:
    flutter run

7. API address configuration
- Non-web Flutter builds use `lib/services/api_host_nonweb.dart`
- Android emulator uses `10.0.2.2`
- iOS simulator and desktop use `localhost`
- Web builds use `lib/services/api_host_web.dart`
- When running the backend locally on another machine, update `api_host_nonweb.dart` or `api_host_web.dart` accordingly.

8. Useful commands
- Show Docker status:
    docker compose ps
- See backend logs:
    docker compose logs --tail 50 api
- Rebuild backend image:
    docker compose build api
- Restart backend only:
    docker compose restart api

9. Notes
- The backend exposes `http://localhost:3000` from the host machine in default setup.
- If using Docker Compose, the backend connects to the database container via `gamerconnect-mysql`.
- If using a local MySQL instance instead of Docker, set `DB_HOST=localhost`.
- If using a physical Android device, replace `10.0.2.2` with the host machine IP.
